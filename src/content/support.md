## Comment nous contacter

Le support de tous les logiciels ShowApp passe par une seule adresse :
[support@showapp.fr](mailto:support@showapp.fr).

- **Depuis l'application** : utilisez le bouton **« Aide et support »**. Votre message nous arrive
  avec les informations utiles (logiciel, version), sans rien avoir à recopier.
- **Par e-mail** : commencez le sujet par le nom du logiciel concerné, entre crochets :
  - `[ShowApp]` pour l'application ShowApp, par exemple `[ShowApp] Export du rider impossible` ;
  - `[StackSheets]` pour StackSheets, par exemple `[StackSheets] PDF CODA non reconnu`.

Pour un problème, décrivez ce que vous faisiez, ce qui s'est passé et ce que vous attendiez. Une
capture d'écran ou le fichier en cause (un PDF Soundvision ou CODA, par exemple) aide beaucoup.

## Questions fréquentes

### ShowApp est-il gratuit ?

Les logiciels ShowApp sont distribués sous licence
[PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0/) : ils
sont libres d'utilisation à des fins non commerciales. Pour un usage commercial, écrivez-nous.

### Comment créer un compte ShowApp ?

Ouvrez l'application sur [app.showapp.fr](https://app.showapp.fr) et choisissez **« Créer un
compte »** sur la page de connexion.

### J'ai oublié mon mot de passe.

Cliquez sur **« Oublié ? »** sur la page de connexion de l'application. Sans réponse
après quelques minutes, regardez dans vos indésirables, puis écrivez-nous.

### StackSheets ne reconnaît pas mon PDF.

StackSheets lit les rapports exportés par Soundvision et par CODA System Optimiser. Vérifiez que
vous avez la dernière version, puis envoyez-nous le PDF avec le sujet `[StackSheets]`.

### Comment mettre à jour mes logiciels ?

L'application Windows de ShowApp et StackSheets vérifient elles-mêmes les nouvelles versions et
proposent la mise à jour. Les dernières versions sont aussi sur les pages
[ShowApp](/showapp) et [StackSheets](/stacksheets).

### Comment faire supprimer mes données ?

Écrivez à [support@showapp.fr](mailto:support@showapp.fr). Le détail de vos droits est sur la page
[Confidentialité](/confidentialite).
