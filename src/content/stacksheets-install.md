- **Windows** : lancez l'installateur `.exe`.
- **macOS** : ouvrez le fichier `.dmg` (macOS 14 Sonoma ou plus récent).
- **Android** : installez le fichier `.apk` ; Android demande d'autoriser l'installation depuis cette
  source.
- **iOS** : StackSheets est distribué par TestFlight, sur invitation. Demandez-la à
  [support@showapp.fr](mailto:support@showapp.fr?subject=%5BStackSheets%5D%20Invitation%20TestFlight).

Chaque version publie aussi un fichier `SHA256SUMS.txt` pour vérifier l'intégrité des fichiers
téléchargés.
